# Mini Deep Learning Framework

A modular deep learning framework built from scratch using PyTorch's `nn.Module` architecture. This project focuses on understanding the internal components of deep learning frameworks by implementing neural network building blocks, optimization algorithms, loss functions, and training utilities.

## Features

### 1. Core Neural Network Components
- Custom Module implementation
- Linear layers
- Sequential container
- Flatten layer

### 2. Activation Functions
- ReLU
- Leaky ReLU
- Sigmoid
- Tanh
- GELU
- Swish
- Softmax

### 3. Loss Functions
- Mean Squared Error (MSE)
- Mean Absolute Error (MAE)
- Binary Cross Entropy (BCE)
- Categorical Cross Entropy (CCE)

### 4. Optimization Algorithms
- Stochastic Gradient Descent (SGD)
- Momentum
- AdaGrad
- RMSProp
- Adam
- AdamW

### 5. Regularization
- L1 Regularization
- L2 Regularization
- Dropout

### 6. Normalization
- Batch Normalization

### 7. Weight Initialization
- Xavier Initialization
- He Initialization

### 8. Learning Rate Schedulers
- Step Learning Rate Scheduler
- Cosine Annealing
- Warmup + Cosine Annealing

### 9. Training Engine
- Custom Trainer
- Forward propagation
- Backpropagation
- Parameter optimization
- Training and validation workflows

## Project Objective

The primary objective of this project is to understand how deep learning frameworks work internally by implementing their fundamental components in a modular and reusable architecture.

Rather than relying entirely on high-level APIs, this project explores the mathematical and computational foundations behind neural network training.
